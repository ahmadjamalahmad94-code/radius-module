## معلّق — قرارات منتج/معماري (لم تُصلَّح عمداً)
1. **hex خام داخل كتل `<style>` المحلية** في صفحات بنمط CSS خاص متماسك: `reports_archive`/`admin_bridge` (نوافذ fcw)، `hotspot_errors` (`.he-*`)، `backups` (`.bkx-*/.bk-*`). الترحيل الكامل لتوكِنات النظام refactor واسع الأثر (وبعضه يكسر تدفّقات AJAX في backups). **توصية:** مركزة CSS نوافذ fcw في ملف موحّد.
2. **`confirm()` في `admin_pricing`** (استعادة الصف/الكل): النمط منتشر في ~29 قالباً عبر الكودبيس؛ استبداله قرار UX على مستوى المنتج لا صفحة مفردة. (عالجنا confirm() حيثما كان معزولاً: licensing/lifecycle/recycle/sync/hotspot_errors.)
3. **توكِن لون برتقالي مفقود** لهوية «قسم حماية البيانات» (`data_protection_nav` تدرّج `#ea580c→#9a3412`): يحتاج إضافة `--hub-orange*` للنظام.
4. **`reports_archive` — قائمة «نوع التقرير» بخيار واحد**: حدّ منتجي مقصود (أرشفة مالية فقط) مشروح بتلميح.
5. **`backups`**: لا توكِن لوني لهوية القسم؛ والصفحة على نظام `.bkx-*` خاص — إبقاؤها لتجنّب كسر AJAX.

## ارتدادات أدخلها الوكلاء وأصلحتُها مركزيّاً
- **`audit_log_index`**: استعادة خطّافات الاختبار `data-audit-log-page` / `data-audit-filter-{router,action,severity,result,search}` / `data-audit-log-rows` / `data-audit-empty` / `data-audit-row` كسمات إضافية بحتة — أعادت 5 اختبارات للأخضر دون مساس بالتصميم الجديد.
- **`settings_page`**: استبدال `alert()` لرفع الشعار برسالة خطأ مضمّنة.
