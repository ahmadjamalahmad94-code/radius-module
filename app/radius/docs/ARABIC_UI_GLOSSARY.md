# قاموس تعريب واجهة radius-module

هذا القاموس يثبت المصطلحات المرئية العامة في الواجهة العربية، مع إبقاء المصطلحات التقنية التي تمثل عقودًا أو أسماء بروتوكولات كما هي.

## مصطلحات الواجهة

| English | Arabic |
| --- | --- |
| Dashboard | لوحة التحكم |
| Settings | الإعدادات |
| Operations | العمليات |
| Reports | التقارير |
| Payment Collection | تحصيل الدفعات |
| Review Queue | طابور المراجعة |
| Dry-run | تجربة جافة |
| Save | حفظ |
| Cancel | إلغاء |
| Create | إنشاء |
| Delete | حذف |
| Search | بحث |
| Filter | فلترة |
| Status | الحالة |

## مصطلحات تقنية تبقى بالإنجليزية

تبقى هذه المصطلحات كما هي عندما تظهر كجزء من عقد تقني أو اسم بروتوكول أو قيمة إعداد: `API`, `RADIUS`, `CoA`, `MikroTik`, `WireGuard`, `PPPoE`, `DHCP`, `CSV`, `PDF`, `Excel`, `JSON`, `Webhook`, `MAC`, `IP`, HTTP methods, JSON keys, URLs, env vars, file paths.
