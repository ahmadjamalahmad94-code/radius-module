لماذا هذا الحلّ؟

عمود «الجهاز / النظام» في فحص البطاقة يحتاج معرفة اسم الجهاز (host-name) ونوع نظام التشغيل (DHCP option 60) لكل MAC. الحلّ الأصلي كان أن يسحب الخادم هذه البيانات من MT API على البورت 8728، لكن لمّا الراوتر خلف NAT أو الفايروول مسكّر، الـ API لا يصل من الخادم.

هذا الحلّ يعكس الاتجاه: نخلّي الراوتر يدفع البيانات إلى الخادم عبر HTTPS كل دقيقتين. الـ outbound HTTPS مفتوح في كل الراوترات تقريبًا (لأنه نفس المنفذ المستخدم للوصول للإنترنت)، فلا يحتاج فتح منافذ خارجية ولا VPN ولا port forwarding.
