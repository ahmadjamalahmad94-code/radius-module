{# ───── Explanation: numbered steps ──────────────────────── #} {% call hub.section("ما هو Webhook ولماذا تستخدمه؟", icon="circle-question") %}
  1. تنبيه فوري بأحداث النظام. عند كل دفعة جديدة، تجديد اشتراك، أو تنبيه أمني — يرسل النظام إشعار HTTP POST لرابط خاص بك.
  2. توقيع آمن بكل طلب. كل طلب يحمل ترويسة X-Radius-Signature تحتوي توقيع HMAC-SHA256 يتم حسابه بالمفتاح السري أدناه. تحقّق من التوقيع قبل الوثوق بالبيانات.
  3. إعادة محاولة ذكية. الفشل المؤقت (أخطاء شبكة أو 5xx) يُعاد بفترات متصاعدة، والفشل النهائي (4xx) يتوقف فورًا.
  4. سجل كامل. كل عملية إرسال محفوظة في سجل الإرسال — يمكنك مراجعتها وإعادة المحاولة يدويًا عند الحاجة.

{# Left: configuration #} {% call hub.section("إعدادات الربط", icon="sliders") %}
رابط الاستقبال *
رابط HTTPS كامل يستقبل طلبات POST. يجب أن يرجع كود استجابة 2xx لاعتبار الإرسال ناجحًا. أي شيء آخر يعتبر فشلًا.
المفتاح السري (HMAC) *
مفتاح سرّي مشترك بين الريدياس وخادم الاستقبال. يستخدم لتوقيع كل طلب عبر HMAC-SHA256. لا تشاركه ولا تضعه في أي مكان عام.
