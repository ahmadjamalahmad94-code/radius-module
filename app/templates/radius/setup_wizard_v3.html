الربط بالخادم (WireGuard + RADIUS)

      
سيُولّد سكربت موحَّد يربط الراوتر بالخادم عبر VPN
         آمن ويُهيّء RADIUS. لا تحتاج لكتابة أي شيء.

    


    

      

        ✅ سكربت الربط جاهز
        
يحتوي السكربت على WireGuard + مستخدم API + RADIUS
           بالكامل. تنبيه: الـ MikroTik Terminal
           يفقد السطور الطويلة عند اللصق المباشر — استخدم
           طريقة /import أدناه (موصى بها).

      


      

        🚀 الطريقة الموصى بها — fetch & import
        
انسخ السطر التالي والصقه في MikroTik Terminal:

        

        
        أمران مفصولان بفاصلة منقوطة ;
          — الراوتر يحمّل الملفّ ثم ينفّذه تتابعياً. سطر واحد
          يضمن عدم فقد /import أثناء
          عرض شريط تقدّم التنزيل.
      


      

        
          للفنّيين فقط
          طريقة قديمة — لصق السكربت كاملاً يدوياً
        
        

          ⚠️ تنبيه: السطور الأطول من 200 حرف قد تنبتر أثناء
          اللصق. لو لاحظت أن
          /user add أو
          /radius add لم يتنفّذا، عُد
          إلى طريقة الـ fetch + import
          أعلاه.

           SSH أو نسخ يدوي.

      

      

        
      

      

        ✅ تم الربط على الخادم وإعادة تشغيل FreeRADIUS

        ⚙️ تفاصيل تقنيّة (لا حاجة لها عادةً)
