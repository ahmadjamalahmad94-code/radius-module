تغيير IP الخروج (Site Exit)

تستطيع توجيه مشتركي هذا الراوتر للخروج عبر IP عام مختلف، بربط الراوتر بـ VPS exit node له IP منفصل. مفيد لتغيير الموقع الجغرافي المرئي، أو لفصل بعض المواقع عن باقي الحركة.

جارٍ تحميل قائمة الـ VPS exit nodes…
لا توجد VPS exit nodes معرّفة بعد.
لاستخدام هذه الخدمة، أضِف عقدة خروج (Exit Node) من إعدادات النظام أولاً — العقدة تحتوي على IP العام الذي ستوجَّه الحركة عبره.
عقدة الخروج (VPS exit node)

اختر الـ VPS الذي ستمرّ منه الحركة. كل عقدة لها IP عام منفصل.
