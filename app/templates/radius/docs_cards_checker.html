{{ _('«إجراءات ذكية» — كل زر شو بيعمل بالضبط') }}

{{ _('آخر قسم وأقواه: شبكة أزرار') }} {{ _('«تحكّم كامل في بطاقة العميل»') }}. كل زر يفتح نافذة تأكيد أنيقة قبل التنفيذ — ما في شيء يصير بضغطة عفوية:

  • {{ _('قطع الجلسة:') }} يعرض لك قائمة الأجهزة المتصلة الآن — تختار جهازًا واحدًا أو الكل (أزرار «تحديد الكل / إلغاء التحديد») ويرسل أمر قطع للمايكروتيك. الأجهزة غير المختارة تبقى متصلة.
  • {{ _('إعادة الاستخدام:') }} يصفّر الوقت المستهلَك — عدّاد البطاقة يبدأ من جديد عند أول اتصال. مفيد كتعويض لزبون أو لإعادة بيع كرت تجريبي.
  • {{ _('قفل MAC:') }} يثبّت البطاقة على جهاز محدد. النافذة تعرض الماكات اللي استخدمت الكرت سابقًا (مع اسم كل جهاز) — اختر منها أو الصق MAC يدويًا (يقبل أكثر من عنوان مفصولًا بفواصل). بعد القفل: أي جهاز غريب ينرفض، والجلسات غير المطابقة تُقطع فورًا. إذا الكرت مقفول أصلًا يصير الزر {{ _('«إدارة قفل MAC»') }}{{ _(': تعديل القائمة أو فك القفل تمامًا.') }}
  • {{ _('تغيير الوقت:') }} {{ _('إضافة أو خصم وقت') }} {{ _('لهذه البطاقة فقط') }} — تختار العملية (إضافة/خصم)، الوحدة (دقائق/ساعات/أيام)، والمقدار. التحديث يوصل للمايكروتيك فورًا إن كانت الجلسة نشطة (CoA)، وإلا يُطبَّق بالجلسة التالية.
  • {{ _('تغيير السرعة:') }} سرعة تنزيل/رفع مخصصة بالـ kbps لهذه البطاقة تتجاوز سرعة الحزمة — والقيمة 0 و0 ترجّعها لسرعة الحزمة. تُطبَّق حيًّا بدون قطع الجلسة.
  • {{ _('تعطيل البطاقة:') }} {{ _('إيقاف مؤقت') }} {{ _('يجمّد الوقت المتبقي') }} — لا ينقص أثناء التعطيل ويرجع كاملًا عند الضغط على {{ _('«إعادة التفعيل»') }}. التعطيل يقطع كل الجلسات النشطة فورًا. (تقدر تكتب سبب التعطيل — اختياري.)
  • {{ _('نقل للمحذوفات:') }} {{ _('الحذف الافتراضي') }} {{ _('آمن') }} — البطاقة تروح لسلة المحذوفات وتقدر تستعيدها من شاشة سلة المحذوفات متى شئت.
