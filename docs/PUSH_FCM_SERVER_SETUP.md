# دفع الإشعارات (FCM) — مركزيّ في لوحة التراخيص

دفع الإشعارات لتطبيق الجوّال **مركزيّ بالكامل**. التطبيق الجوّال تطبيق
عالميّ واحد (`com.hoberadius.app`) يتّصل بكل نسخ الراديوس، ومشروع Firebase
مركزيّ **واحد** يملكه فريق المزوّد في **لوحة التراخيص** (radius-module-admin).

> ⚠️ **وحدة الراديوس لا تَحمل مفتاح Firebase ولا تُرسل FCM إطلاقًا.** لا يوجد
> ملفّ حساب خدمة على خادم العميل، ولا متغيّر بيئة، ولا حزمة `firebase-admin`.
> كل ذلك انتقل إلى لوحة التراخيص.

---

## كيف يَعمل (مرجع سريع)

1. **تسجيل رمز الجهاز:** تطبيق Flutter يُسجّل رمز FCM عبر الراديوس:
   `POST /api/v1/devices/push-token` بجسم `{ "token": "<fcm>", "platform": "android" }`
   (يُلغيه عند الخروج عبر `DELETE /api/v1/devices/push-token`). الراديوس
   **يُحوّل** التسجيل إلى لوحة التراخيص عبر الجسر الموقَّع (مصادقة
   `license_key`)، فتُخزَّن الرموز مركزيًّا مرتبطةً بالعميل. الراديوس لا يُخزّن
   رموزًا محلّيًّا.
2. **إنشاء إشعار:** حين يُكتب إشعار محلّيّ في الجرس (`notify()` →
   `panel_notifications`)، يُحوّل الراديوس طلب الدفع (العنوان/النصّ + `data`)
   إلى لوحة التراخيص عبر الجسر — fire-and-forget. إشعارات الجسر (مصدرها اللوحة
   أصلًا) لا تُحوَّل تفاديًا للتكرار.
3. **الإرسال:** لوحة التراخيص تَحلّ العميل من `license_key`، وتُرسل FCM لكل
   أجهزة ذلك العميل المُسجَّلة، وتُقلّم الرموز الميّتة.
4. **اختبار:** زرّ **«أرسل إشعار تجريبي»** في مركز الإشعارات يُحوّل دفعة
   اختبار (mode=sync) للوحة وتُبلِغ بالنتيجة.

```
التطبيق ──register token──▶ الراديوس ──bridge──▶ لوحة التراخيص (المخزن المركزيّ)
إشعار على الراديوس ──bridge: forward_push──▶ لوحة التراخيص ──FCM──▶ التطبيق
```

## إعداد المزوّد (مرّة واحدة، في لوحة التراخيص فقط)

في **لوحة التراخيص** (radius-module-admin) ← **الإعدادات** ← تبويب **«دفع
الإشعارات (Firebase)»**: ارفع ملفّ `firebase-admin-sdk.json` لمشروع
`hoberadius`. يُخزَّن بأمان (ملفّ `instance/` مقيَّد الصلاحيات + نسخة مشفّرة
احتياطيّة) ولا يُعرَض محتواه أبدًا. مقصور على المالك (سوبر أدمن). كما يجب أن
تكون حزمة `firebase-admin` مثبّتة في بيئة لوحة التراخيص (`pip install
firebase-admin`، مضمَّنة في `requirements.txt` هناك).

> لا حاجة لأيّ خطوة على خوادم العملاء. تكفي تهيئة **ربط لوحة التراخيص**
> (`HOBERADIUS_ADMIN_BASE_URL` HTTPS + `HOBERADIUS_LICENSE_KEY`) ليَعمل التحويل.

## السلوك عند غياب الاعتماد مركزيًّا

إن لم يُرفَع اعتماد Firebase في لوحة التراخيص (أو غابت الحزمة هناك):

- لوحة التراخيص تُعطّل الإرسال **بهدوء** (no-op) وتُرجع `fcm_disabled`.
- اللوحة + مركز الإشعارات داخل التطبيق + إشعارات ويندوز **تَعمل كالمعتاد**.
- زرّ الاختبار في الراديوس يُظهر «دفع الجوال غير مُفعَّل مركزيًّا».
