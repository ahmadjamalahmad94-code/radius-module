# Customer Quick Start

The setup wizard prepares MikroTik configuration in safe steps:

1. Configure internet uplink.
2. Verify internet.
3. Configure VPN/RADIUS.
4. Verify VPN/RADIUS/API reachability.
5. Optionally configure Hotspot.
6. Optionally configure Broadband/PPPoE.
7. Review added services.

Copy each script into MikroTik Terminal, then paste validation output back into
the wizard when asked.
