# Setup Wizard Operator Guide

1. Create or resume a wizard run.
2. Generate preview scripts and ask the customer to paste them manually unless
   guarded live apply has been explicitly enabled for a controlled pilot.
3. Verify each required gate before moving forward.
4. Paste router inventory before smart Hotspot or Broadband planning.
5. Use dry-run before any apply.
6. Keep support bundles sanitized and attach them to internal support tickets.

Never enable live apply for a customer setup without a current router backup,
clear rollback plan, and a verified management access path.
