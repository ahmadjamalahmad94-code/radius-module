# Setup Wizard Pilot Checklist

- Live apply flag is off by default.
- Router backup exists.
- Management access path is confirmed.
- Internet verification is successful.
- VPN/RADIUS verification is successful.
- Inventory snapshot is current.
- Dry-run has no blocking errors.
- Confirmation phrase is provided by an operator.
- Rollback preview only targets `HOBERADIUS_SETUP` tags.
- Support bundle contains no plaintext secrets.
